# 剪存 — 部署說明

這是一個可以「加到手機主畫面」並出現在 Android 分享選單裡的網頁 App。
資料存在你手機瀏覽器的本機儲存空間（localStorage），不會上傳到任何伺服器。

---

## 第一步：把這 4 個檔案 + icons 資料夾放到網路上

你需要一個能放靜態網頁檔案、並提供 **https** 網址的地方（一定要是 https，Android 的分享功能才會生效）。以下兩個都免費，選一個就好：

### 方法 A：GitHub Pages（推薦，網址固定、可長期使用）

1. 到 https://github.com 註冊帳號（如果還沒有）
2. 新增一個 repository，例如取名 `jian-cun`
3. 把這個資料夾裡的所有檔案（`index.html`、`manifest.json`、`sw.js`、`icons/` 整個資料夾）上傳上去
   - 網頁介面：進 repo → Add file → Upload files → 把檔案拖進去 → Commit
4. 進 repo 的 **Settings → Pages**
   - Source 選 `Deploy from a branch`
   - Branch 選 `main`，資料夾選 `/ (root)` → Save
5. 等 1-2 分鐘，頁面會給你一個網址，長得像：
   `https://你的帳號.github.io/jian-cun/`
6. 用手機瀏覽器打開這個網址

### 方法 B：Netlify Drop（最快，但沒帳號的話網址是隨機的、不保證長期存在）

1. 到 https://app.netlify.com/drop
2. 把整個資料夾拖進網頁裡
3. 會立刻給你一個 https 網址，用手機瀏覽器打開

---

## 第二步：加到手機主畫面

1. 用 **Chrome** 打開部署好的網址
2. 右上角選單 → 「新增至主畫面」（或畫面下方會自動跳出「安裝應用程式」的提示，直接按安裝）
3. 主畫面上會出現「剪存」的圖示

⚠️ 一定要用 Chrome 開，並且真的「安裝」到主畫面（不是只加書籤），分享功能才會啟用。

---

## 第三步：測試分享功能

1. 打開 Threads（或任何 App）→ 分享一則貼文
2. 分享清單裡應該會出現「剪存」
3. 點下去，會直接打開 App 並自動帶入網址，填一下心得跟分類，按儲存就好

如果分享清單裡沒看到「剪存」：
- 確認網址開頭是 `https://`（不是 http）
- 確認是「安裝」到主畫面，不是只存書籤
- 有時候要重開一次 Chrome、或把手機重新整理一下分享清單的快取（設定 → App → Chrome → 儲存空間 → 清除快取，不是清除資料）才會出現

---

## 關於資料

- 資料存在你「安裝這個 App 的那個瀏覽器」裡，換手機、砍掉重裝、清瀏覽器資料都會不見
- 建議定期用 App 裡「匯出備份」存一份 JSON 檔到雲端硬碟，之後要復原就用「匯入備份」
- 這個版本沒有 AI 語意搜尋（會需要你自己的 API 金鑰跟費用），改成本地關鍵字搜尋：可以搜標題、心得、網址、分類名稱
